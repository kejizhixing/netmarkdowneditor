# 本地简约般双页面----📝 Markdown 编辑器 · Base64 图片内嵌版（2.0.0 以下这是本地离线）
# 青笺更优雅的 Markdown 公众号排版工具告别复杂工具。Markdown 写作，一键复制到公众号，专为公众号创作者设计的本地优先编辑器（2.0.1 以上版本是公众号编辑器MD般）
> 一款功能强大的 Windows 桌面 Markdown 编辑器，支持实时预览、Base64 图片内嵌、多格式导出、系统信息检测等。专为开发者和写作者设计，绿色便携，开箱即用。

---

## ✨ 主要功能

- **分栏编辑与实时预览**  
  左侧编辑，右侧 WebView2 实时渲染，完美支持 Markdown 语法。
- **图片智能内嵌**  
  本地图片自动压缩并转为 Base64 编码，文档脱离图片仍可显示；网络图片保留链接。
- **多格式导出**  
  支持导出为 Markdown、纯文本、HTML、PDF，以及**微信公众号 HTML**（自动适配后台编辑器，图片已转为本地文件并复制到剪贴板）。
- **文件关联**  
  可在设置中注册 `.md` 文件，双击直接调用本软件打开。
- **系统信息与开发环境检测**  
  查看电脑硬件配置、所有已安装软件、环境变量、开发语言运行时（Python、Node.js、Java 等），并提供 Ollama AI 本地部署指导。
- **安全与授权**  
  软件需有效的 `license.lic` 授权文件，保护版权。首次运行需同意用户许可协议。
- **其他特性**  
  拖拽/粘贴插入图片、自动保存、右键菜单（清空、导出）、菜单栏滚动信息等。

## 💻 运行环境

| 组件              | 要求                                   |
|-------------------|----------------------------------------|
| 操作系统          | Windows 10 版本 1809 及以上（推荐 Windows 10/11） |
| 运行时（自包含版）| **无需任何额外安装**，exe 已内置所有依赖 |
| 运行时（框架依赖版）| 需安装 [.NET 8 桌面运行时](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)（选择 Windows x64） |
| 其他              | WebView2（Windows 10 1809+ 已内置）      |

## 📥 下载与使用

1. 从 [Releases 页面](../../releases) 下载最新版本：
   - **自包含版**（体积较大，但无需安装 .NET）  
   - **框架依赖版**（体积小，需安装 .NET 8 运行时）
2. 将下载的压缩包解压到任意目录，**确保 `license.lic` 与 `MarkdownEditor.exe` 在同一文件夹**。
3. 双击 `MarkdownEditor.exe` 启动。
4. （可选）首次使用请在“设置 → 文件关联设置”中注册 `.md` 文件。

> ⚠️ 若提示缺少 `license.lic`，请联系开发者获取授权文件。
